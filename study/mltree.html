決策樹 (CART)

核心概念

想像您正在玩「20個問題」遊戲，心中想著一個物件，電腦要猜是誰。這就是 CART 的運作原理：尋找資料中最具區辨力的特徵，將資料一分為二，不斷重複。

原理解析：如何選出「最佳問題」？

電腦不是憑感覺提問，而是透過數學指標來計算切割點：

Gini 不純度 (Gini Impurity) 或 熵 (Entropy)：
這些指標用來衡量資料的「混亂程度」。如果一個節點裡混雜了各種不同類別（如既有A類又有B類），不純度就很高。決策樹的目標是找到一個特徵切分點，使得切分後的子節點不純度下降最多（Information Gain 最大化）。

🏛️ 應用案例：紅樓夢作者歸屬

分析《紅樓夢》前八十回與後四十回。決策樹可以畫出一張圖：
「如果『兮』字頻率低於 X，且『於』字高於 Y，則判定為曹雪芹所著」。
最大優點：可解釋性高 (White Box Model)，我們可以清楚看到判斷路徑。

隨機森林 (Random Forest)

核心概念

決策樹容易鑽牛角尖（過度擬合）。隨機森林的解法是：「不要只依賴一位專家，而是培養一座森林。」透過群體決策來消除個體的偏見。

原理解析：Bagging 與特徵隨機性

隨機森林之所以強大，依賴於兩層隨機性來降低變異數 (Variance)：

  • Bootstrap Aggregating (Bagging)：每棵樹訓練時，並非使用全部資料，而是從原始資料中「有放回地隨機抽取」樣本。這確保了每位專家看到的案例略有不同。
  • 特徵隨機性 (Feature Randomness)：在每個節點分裂時，樹只能從「隨機選取的一部分特徵」中挑選最佳特徵。這強迫樹去學習不同的面向，避免所有樹都長得太像（降低相關性）。

🌳 隨機性 (Randomness)

每棵樹只讀一部分資料、用一部分特徵，確保多樣性。

🗳️ 集成投票 (Ensemble)

透過多數決 (Classification) 或平均值 (Regression) 產出最終結果。

R 語言
Python
library(randomForest)
set.seed(42)

# 步驟 1: 建立隨機森林

rf_model <- randomForest(Species ~., data = iris, ntree = 500, importance = TRUE)

# 步驟 2: 查看重要性
# 哪種特徵最關鍵？
varImpPlot(rf_model, main = "特徵重要性")
from sklearn.ensemble import RandomForestClassifier
from sklearn.model_selection import train_test_split

# 步驟 1: 分割數據 (80% 訓練, 20% 測試)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2)

# 步驟 2: 建立模型
# n_estimators=100: 建立 100 棵樹

# 步驟 3: 預測

K-Means 分群

核心概念

前兩種是「監督式學習」（有標準答案），K-Means 則是「非監督式學習」（沒有答案）。 想像挖掘出數千片未知陶片，我們不知道有哪些朝代，只想知道「哪些東西長得像」。

原理解析：最小化距離平方和

K-Means 的數學目標是最小化 **組內誤差平方和 (Within-Cluster Sum of Squares, WCSS)**。演算法透過迭代兩個步驟來達成：

  1. 分配 (Assignment)：計算每個資料點到 K 個中心點的歐幾里得距離 (Euclidean Distance)，將點歸類到最近的中心。
  2. 更新 (Update)：重新計算每個群體的「質心」（所有點的座標平均值），將中心點移動到新的質心位置。

這兩個步驟會不斷重複，直到中心點不再移動（收斂）為止。

📜 應用案例：文本自動歸類

將一位作家的所有書信丟進去，K-Means 可能會自動將其分為「家書」、「公文」和「情書」三類，完全不需要人工先閱讀。適合探索性研究。

總結與建議

需要解釋規則（如風格學特徵）：選 決策樹。

只在乎準確率與泛化能力：選 隨機森林。

資料無標籤/未知結構：選 K-Means。
